# Master specification coverage

Audit of 2026-10-19 of the code against `Intuit_Software_Clone_Master_Project_Context_v0.1.pdf` (the master context, sections 1–36). `docs/requirements-matrix.md` tracks the finishing plan (FP-nn); this file tracks the **specification's own bullet lists**, so nothing in the master document is lost behind the plan. The specification does not assign APPROVED/DEFERRED/PROHIBITED/UNDECIDED to individual bullets (section 29), so where a bullet has no recorded decision and its shape would require inventing behaviour, it is listed as **NEEDS DECISION**, not built.

Statuses: **DONE** (implemented and covered by a named automated test), **PARTIAL**, **NOT DONE**, **NEEDS DECISION** (the specification leaves the behaviour open), **DEFERRED** (the specification or the owner defers it; architectural readiness noted), **BLOCKED** (waits for an external input). Nothing here claims production readiness.

## 25 AI — PARTIAL (help assistant only; suggestions and OCR DEFERRED)

A read-only help assistant exists (`assistant.md`): it explains the product from a built-in catalogue, can quote the member's own aggregate figures read through the report services under their permissions, and optionally has a configured language model word the reply. It has no tools and cannot post or change records. No AI suggestion, categorization or document-reading feature exists. Any such feature must be reviewable and must not write financial data.
