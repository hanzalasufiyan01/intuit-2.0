# Full-product requirements matrix

The single authoritative status list for the completion mandate. Statuses: **VERIFIED COMPLETE** (implemented and covered by a passing automated test run in this repository), **IMPLEMENTED BUT UNVERIFIED** (written, not exercised), **PARTIAL**, **NOT IMPLEMENTED**, **BLOCKED**, **EXPLICITLY DEFERRED** (a documented decision, still visible here). Nothing is marked complete without a test or run named in the Evidence column.
